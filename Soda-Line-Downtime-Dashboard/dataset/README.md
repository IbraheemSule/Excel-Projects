Dataset

This folder contains the dataset used for the Soda Line Downtime Dashboard project.

Dataset File

soda_line_downtime_data.xlsx

The dataset contains production downtime records used to analyze downtime patterns, causes, production lines, machines, shifts, and operational performance.

Purpose

The dataset is used to:

Analyze total production downtime
Identify major downtime causes
Compare downtime across production lines
Analyze downtime by machine
Examine downtime patterns over time
Compare downtime across production shifts
Support the development of the interactive Excel dashboard
File Format
Format: Excel Workbook (.xlsx)
File Type: Raw Dataset
Usage

The dataset can be opened with Microsoft Excel or another spreadsheet application and is used as the source data for the dashboard analysis.
